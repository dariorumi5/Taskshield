# Taskshield

Taskshield is a web application for managing incidents.

## Prerequisites

- PHP
- MySQL
- Apache

## Installation

1. Clone the repository
2. Create a database and user
3. Import the SQL file
4. Open Xampp and start Apache and MySQL
5. Access the application at http://localhost/Taskshield/index.php
