# Taskshield

Taskshield is a web application for managing incidents.

## Prerequisites

- PHP
- MySQL
- Apache

## Installation

1. Clone the repository
4. Open Xampp and start Apache and MySQL
5. Open PHPMyadmin
6. Import the SQL file
7. Access the application at http://localhost/Taskshield/index.php
